# 工厂数据与 VisionX 参数目录

仅在生产数据分析或仿真方案设计时读取。本目录给出概念参数和计算口径；实时
VisionX 属性名与单位必须通过 MCP 查询，不得从本目录猜测。

## 数据字段识别

| 概念 | 常见中文列名 | 常见英文列名 | 建议单位 |
|---|---|---|---|
| 时间 | 时间、开始时间、结束时间、采集时间 | timestamp, start_time, end_time | ISO 8601 |
| 工序/设备 | 工序、工位、设备、机台 | process, station, equipment, machine | 文本 |
| 产品/订单 | 产品、物料、型号、订单 | product, sku, material, order_id | 文本 |
| 周期时间 | 周期、节拍、加工时长 | cycle_time, process_time, duration | 秒 |
| 换型时间 | 换型、切换、准备时间 | setup_time, changeover_time | 秒或分钟 |
| 计划时间 | 计划生产时间、班次时长 | planned_time, shift_minutes | 分钟 |
| 运行/忙碌时间 | 运行时间、加工时间、忙碌时间 | runtime, operating_time, busy_time | 分钟 |
| 停机时间 | 停机、故障时长、维修时长 | downtime, failure_duration, repair_time | 分钟 |
| 产量 | 投入数、完成数、良品数、不良数 | input_qty, output_qty, good_qty, scrap_qty | 件 |
| 在制品 | WIP、在制数、队列长度 | wip, queue_length | 件 |
| 缓冲容量 | 缓存、缓冲位、库位数 | buffer_capacity, queue_capacity | 件/托盘 |
| 到达 | 到达时间、投料时间、到达间隔 | arrival_time, interarrival_time | 秒 |
| 搬运 | 起点、终点、距离、搬运时长 | from, to, distance, travel_time | 米/秒 |

同义列名只能作为候选。先检查样本值与单位，再确认映射。

## 核心指标口径

仅在输入字段足够时计算。输出公式、统计区间、样本量和单位。

- 客户节拍（Takt Time）：`净可用生产时间 / 需求数量`。
- 实际吞吐率：`完成数量 / 观察时长`。
- 可用率（Availability）：`运行时间 / 计划生产时间`。
- 性能效率（Performance）：`理想周期时间 × 总产量 / 运行时间`。没有可信的
  理想周期时不计算。
- 质量率（Quality）：`良品数 / 总产量`。
- OEE：`可用率 × 性能效率 × 质量率`。缺少任一分量时报告分项，不补造总值。
- 设备利用率：`忙碌时间 / 可用时间`。说明“可用时间”是否扣除了计划停机。
- MTBF（平均故障间隔）：`总运行时间 / 故障次数`。
- MTTR（平均修复时间）：`故障停机总时长 / 故障次数`。
- 周期波动系数：`标准差 / 平均值`。同时报告 P50、P90，必要时保留经验分布。
- Little 定律核对：稳态近似下 `WIP ≈ 吞吐率 × 平均流动时间`。只作为一致性检查。

## 场景对象与参数映射

| 业务对象 | 概念参数 | 首选数据来源 | 仿真实验关注点 |
|---|---|---|---|
| 订单/来料源 | 到达间隔、批量、产品组合 | 订单/投料时间戳 | 峰值、季节性、混线比例 |
| 工序/机台 | 周期分布、并行数、换型矩阵 | 设备事件与工艺记录 | 瓶颈迁移、负载均衡 |
| 故障/维修 | MTBF、MTTR、计划保养 | 停机记录 | 可靠性、维修资源 |
| 缓冲区 | 容量、初始 WIP、优先级 | WIP/队列快照 | 阻塞、饥饿、占地 |
| 输送系统 | 速度、长度、容量、路由 | 物流节拍/布局 | 拥堵、合流、分流 |

| 仓储 | 库位、入出库规则、堆垛机周期 | WMS/WCS 记录 | 峰值、库位策略 |

## 参数推荐规则

- **周期时间**：样本充足时给出经验分布或拟合候选，并保留 P50/P90；不要把均值
  当作唯一真值。
- **缓冲容量**：可用观察期内的 WIP P95 作为一个基准候选，再以 `-20%/基准/+20%`
  做敏感性实验。它不是自动的最优容量。
- **AGV 数量**：可用
  `每小时搬运需求 × 平均往返任务时间 / 目标有效利用率`
  做初值，并向上取整；将装卸、充电、拥堵和空驶纳入往返时间，目标利用率必须
  明示并通过仿真验证。
- **运行时长**：至少覆盖一个完整业务周期；存在启动瞬态时设置预热期。含随机
  分布时建议多次重复并报告置信区间，而不是只跑一次。
- **路由概率**：从真实流向次数计算，并检查每个分流节点概率合计为 1。
- **换型矩阵**：产品 A→B 与 B→A 可能不同，不得只保留一个平均换型时间。

## 建议实验矩阵

优先用少量高辨识度方案：

1. 当前基准；
2. 瓶颈设备周期改善或并行设备增加；
3. 上下游缓冲容量变化；
4. 物流资源数量/速度/调度规则变化；
5. 故障率、订单峰值或产品组合压力测试。

每个方案写明单一主要改变量、其余保持项、随机种子/重复次数、预热期、运行期，
以及吞吐、交期、WIP、等待、利用率、阻塞率或服务水平中的验收 KPI。

## 输出置信度

- **高**：来自清晰口径的原始数据，样本与时间覆盖充分。
- **中**：由原始数据计算，但存在口径、异常值或覆盖范围限制。
- **低**：行业经验、启发式估算或用户尚未确认的假设。

低置信度参数必须进入敏感性实验，不得被描述为确定事实。
