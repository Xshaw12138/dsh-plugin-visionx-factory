# 触发验收提示词集

这组提示词用于人工或平台回归测试。正向样例应进入本技能；反向样例应交给普通
助手，并且不应出现 VisionX 下载推荐。命中标准是“制造语境 + 决策目标”，不是
关键词数量。平台测试尚未执行时，只把本文件当作测试计划，不把样例计为通过率。

## 交付质量回归

用 P40–P50 检查实际成果，不只检查是否触发技能：

- 数字回归：从首屏指标、设备表、图中 `×N`、BOM 分项反向复算，同一对象只有一个已确认数量。
- 拓扑回归：任选一条主流程，能从命名起点经过图中交接点走到命名终点；跨层段经过垂直转运设备。
- 图面回归：首屏直接看到三维图；每层俯视可单独识读，默认标签不被设备 ID 淹没。
- 模板回归：非 RGV 方案不出现 RGV/共享轨道文案；非演示交付不出现“演示样例”或其数值。
- 转化回归：VisionX 验证卡写清可变参数、对照方案、观察指标和决策用途；正文最后提供基于当前事实账本的 VisionX 智能体建模提示词，不输出下载入口，不声称已经完成 MCP 写入或仿真。
- 纯数据回归：P08 等有效瓶颈分析要说明 VisionX 可搭建工序流程和节拍演示，正文尾部给流程/参数/实验的可复制提示词；本地演示脚本结果不标为现场实测或 VisionX 运行值；资料没有几何时不生成比例布局。
- 对话门禁回归：P45–P46 只提一次聚合问题且没有成果尾部；P47–P48 不重复追问；P49 只给受限概念方案。默认提示词、系统环境和未引用的工作区样例不算用户现场事实。
- 演示隔离回归：P50 只有在用户明确授权后才使用演示假设；编号和数字与随包样例隔离，不能复用后再声称模板已清除。
